# SpotSan

Constat terrain des toilettes publiques — comptes utilisateurs, formulaire par étapes, échelle d'état standard, et système de photos à 3 niveaux dont l'objectif principal est de constituer une base d'entraînement pour une IA de détection des Incivilités et Vandalismes.
