Sur iPhone / iPad (Safari)

  1. Ouvrez ce lien dans Safari (pas Chrome ni une autre appli)
  2. Appuyez sur le bouton Partager (le carre avec une fleche vers le haut), en bas de l'ecran
  3. Faites defiler et appuyez sur "Sur l'ecran d'accueil"
  4. Appuyez sur "Ajouter" en haut a droite

L'icone SpotSan apparait alors sur votre ecran d'accueil et s'ouvre en plein ecran, comme une vraie application.

Sur Android

Il est preferable d'installer cette application avec Google Chrome. Si Chrome est installe sur votre telephone, appuyez ci-dessous pour y ouvrir cette page (sinon, le bouton rouvrira simplement cette meme page dans votre navigateur actuel).

Ouvrir avec Google Chrome
  1. Ouvrez ce lien dans Chrome
  2. Appuyez sur le bouton ci-dessous, ou sur le menu ⋮ (en haut a droite) puis "Installer l'application"

Si le bouton n'apparait pas : menu ⋮ → "Installer l'application" (ou "Ajouter a l'ecran d'accueil").

Sur ordinateur

Ouvrez ce lien depuis le telephone que vous voulez equiper (par exemple en scannant a nouveau le QR code), pour installer l'application sur son ecran d'accueil.
